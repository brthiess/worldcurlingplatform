# World Curling Platform specification

The canonical specification is the local tracker issue [WCP-SPEC-001](.scratch/world-curling-platform/spec.md), produced using the user-invoked [to-spec skill](https://www.aihero.dev/skills-to-spec).

It captures the agreed product, user stories, implementation decisions, testing boundary, exclusions, and initial Curling Crawler data source. Use it as the parent for ticket decomposition; it is not a single implementation ticket.

The approved post-audit refinement organizes acceptance around seven demonstrations and records six exceptional-scenario deferrals with minimum safeguards. The user has accepted P-01 through P-05, including a 16-team four-player triple-knockout main demonstration, bounded discipline/format coverage, team-season representation, rotating-five core identity, ranking publication gates, and a minimum analytics inventory. These accepted limits supersede earlier broader coverage/metric examples; other supporting requirements remain. This refinement authorizes documentation changes only, not implementation.

Testing includes substantial domain-unit coverage, real PostgreSQL integration checks, and the agreed browser workflows, reflecting the user's explicit testing requirement during specification.
