# Create a new team identity when permanent players change

The user explicitly chose to create a new team ID when a core player permanently joins or leaves. This replaces the proposed schema's model of one enduring team identity surviving permanent core-roster changes. Keeping the older identity preserves the historical team that earned its results, while the new composition is independently identifiable. Temporary event/game substitutions remain separate under ADR 0004. Ranking entitlement and carryover follow the applicable WCTRS rules rather than being granted by identity equality.

In Q47-Q52 on 2026-11-07, the user clarified that alternate/coach changes do not create a new team and accepted identity reuse for the same core-player set and discipline, including across seasons or after a break. Name and playing-position changes do not determine identity. Event entries automatically create/reuse teams when core membership is known; incomplete entries may remain provisional. Teams can participate and appear publicly before World Curling administrators resolve issues after the fact.

Team lineage is explicitly deferred entirely for the offer. Distinguish factual identity corrections from real roster transitions, preserve audit/publication history, and resolve duplicate records explicitly. This identity convention does not replace season-specific ranking roster/eligibility/allocation rules.
