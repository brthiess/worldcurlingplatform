# Keep event lineups separate from registered season rosters

Selecting a registered team creates an event entry with a prefilled event lineup; changing that lineup does not itself modify the registered season roster. An organizer may also assemble an entry from existing or newly created players without creating a permanent registered team. The user accepted this boundary to support substitutes, one-off teams, and manual organizer entry without unintentionally changing wider team records or ranking associations.

Linking an entry to a registered team is explicit, and ranking eligibility remains a separate assessment. Incomplete lineups and unresolved provisional player identities are visible states, not evidence that sporting or ranking requirements have been met. Q44/Q47 establish that a permanent core-player change creates a new team identity, excluding alternate/coach changes and temporary event substitutions. Q49/Q52 allow entries with identified core membership to automatically create/reuse teams and appear publicly, with World Curling corrections afterward. Incomplete entries can remain provisional. See ADR 0006.
