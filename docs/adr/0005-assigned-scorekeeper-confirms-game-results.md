# Let the assigned scorekeeper confirm a game's result

The assigned scorekeeper can confirm the final result without a second approver or an additional results-official permission. The user explicitly chose this simplification so a volunteer can complete the scoring workflow in small events. Live scores remain provisional, while confirmation records the responsible person/time and advances the competition draw. This separates fan-visible updates from results that control competition progression without imposing a two-person signoff.

In Q35, the user further chose to let the scorekeeper correct confirmed results without administrator approval, with an audit trail. In Q36, they authorized event organizers to modify affected brackets as needed, rather than requiring an administrator dispute-resolution workflow. Q41 preserves finalized snapshots while allowing corrections, changed-result flags, and revised organizer finalization. Q58 separately grants explicitly authorized feeds scorekeeper-equivalent game confirmation/correction, with organizer actions separately scoped; no extra human confirmation is required for those feeds.
