# Delegate scoped authority instead of granting universal administration

World Curling controls explicit delegation of administrative authority. Authorized personnel in other organizations, such as Curling Canada, may approve events within their assigned scope without becoming universal World Curling administrators. Organizers administer assigned events, volunteers receive narrower event permissions, and partner API clients follow scoped permissions with the same validation and audit requirements as human submissions. This supports distributed event operations while retaining accountable control over official records; self-registration alone confers no authority over an existing player profile, organization, or sport record.

The user accepted this direction for the proposed offer. In Q15, they also accepted configurable scopes using geography, organizer affiliation, discipline, event category, and named exceptions, with approval responsibility visible for each application. Event approval does not automatically grant ranking publication authority. In Q22, they accepted one responsible approval authority and assigned reviewer per application, explicit reassignment, and reasoned World Curling overrides to resolve disputes. Initial-offer default: delegation grants no implicit right to delegate further; additional grants remain World Curling-controlled. Advanced delegation policy is deferred under the user's simplicity instruction. This does not imply that World Curling has approved these policies.
