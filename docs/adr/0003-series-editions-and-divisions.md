# Separate recurring series, dated editions, and divisions

The platform distinguishes a recurring event series from each dated event edition and from the separately run divisions within that edition. Each division owns its entries, competition format, games, and results; an edition containing only one competition still has one division. The user accepted this structure so a multi-discipline event can share its organizing context without sharing competition records, and next year's registration does not overwrite past editions.

Discipline, eligibility category, and competition stage remain separate concepts to define. This accepts the proposed schema's event hierarchy for the user's offer; it is not blanket approval of that schema or World Curling endorsement.
