## Failures corrected during verification

- Initial install used Drizzle `0.45.1`; Better Auth `1.7.18` requires at least `0.45.2`. Pinned compatible `0.45.4`; no force/legacy peer override.
- An early test wrote an additional grant onto the read-only demo persona, changing its expected game count. Removed that abandoned test-only grant once and assigned the repeatable test grant to a separate fixture account.
- Rapid manual suite repetitions hit the real 10/minute credential rate limit (429). The limit was retained; subsequent runs after its window passed. No authentication bypass was introduced.
- A wrapped draw label included option text in Playwright's exact label lookup. All three width tests initially timed out. Replaced it with an explicit label/control association; keyboard, label lookup and all width tests passed.
- axe's open Playwright peer range installed `playwright-core 1.65` beside runner `1.57`, causing a type mismatch. Explicitly pinned the shared core to `1.57.0`; types and axe checks pass. Installing during the earlier run also invalidated that run's HTML-reporter module path; the clean rerun generated its report successfully.
- PostgreSQL CHECK expressions permit UNKNOWN. Added a separate applied migration explicitly requiring non-null points for `played` scores; original applied SQL was preserved. Removed a fixture label referring to nonexistent game 5; upcoming unresolved opponents now read `Opponent to be assigned`.
- Final audit found a low-severity esbuild Windows development-server advisory through the initial tsx release. `npm audit fix` alone did not resolve it; updating pinned tsx to `4.23.15` installed patched esbuild and the full audit is now clean. Domain coverage, worker probe and types passed again afterward.
