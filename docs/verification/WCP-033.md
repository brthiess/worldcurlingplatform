# WCP-033 — four-player event assessments and awards

Work is confined to `ticket/WCP-033` in the assigned worktree. This record reports local verification; independent integration review and tracker closure belong to the coordinator. No world ranking list is published by this slice.

## Delivered behavior

A current global World Curling administrator reviews a frozen division result, records the exact historical ranking/cutoff, source/rule edition, event and entry eligibility, official regulars and actual participation, then queues an event assessment. The real pg-boss worker calculates exact contributions, factor stages, final SFM, series metadata and entry awards. The persistent screen shows evidence, issues, exclusions, exact fractions, delivery history and immutable revisions. Ordinary labeled controls complete a supported assessment; JSON import is optional. Organizer authority does not expose private global ranking evidence.

Inputs pin exact WCP-027 finalization bytes/version/digest and the current sporting-source digest, plus scoped current official-roster evidence, rules/sources, historical edition/pre-event field, policy, derived calculation field, actor/audit and implementation identity. The worker reads only this manifest. Inputs, results, delivery history and receipts cannot be overwritten; corrections create direct revisions. Failed deliveries may retry the original input and retain failure history. Blocked evidence requires a new revision. No manual total is accepted.

Event roster eligibility is distinct from starting entitlements and platform core identity. An explicit sourced event review pins current official regulars/identities and roster/rule references. Missing unused starting ownership or amounts cannot block an otherwise complete event award, and the underlying draft starting record stays draft. Relevant unresolved identities, stale rosters, missing required review or actual throughout-play participation still block. Four-regular and five-regular rules are tested separately. Informational biographies do not participate.

Actual published template/revision/graph and frozen game/seed associations establish the single-knockout factor when available. Later editable display text cannot decide it. Legacy events require explicit sourced actual-format review; unknown/conflicting classifications block. Required unscheduled games from accepted019 are included. First-playoff identity is required only where the losing-record reduction depends on it; planned times do not invent an order or block an unrelated award.

`engineIdentity` records individual actual implementation/policy/dependency file hashes, a reproducible SHA-256 code revision and Node version, including dirty development bytes. Production pins this at build and workers pin their loaded implementation. A same-label delivery with a different implementation fails durably before calculation, including on retry. This is bounded replay evidence, not a version-hosting service.

## Meaningful limitations

This is men's/women's four-player event assessment, not list selection, starting ownership/carryover, publication, mixed doubles or automatic historical cascades. Future list consumers must require their own reviewed/current complete starting evidence and adjustments; event completion does not waive them. The known accepted single profile is mapped explicitly; additional mappings follow accepted format work, while complete sourced legacy cases remain supported.

Uncovered/bounded checks include exhaustive malformed-body/source-edit permutations, every bronze/preparation error permutation, every optional allocation in browsers, hard process death/lease expiry/database-outage recovery, automatic source authenticity certification, non-Chromium engines and hosted providers. Meaningful supported arithmetic and required-unknown branches are tested; coverage percentages do not erase gaps. Actual durable retries and injected transactional failures are exercised; comprehensive exceptional recovery remains deferred. Hosting/domain remain user-pending.
